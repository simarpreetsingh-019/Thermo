# Security policy

Please report security problems privately, not in public issues:
use GitHub's **[Report a vulnerability](https://github.com/simarpreetsingh-019/Thermo/security/advisories/new)**
button, or DM [@simarpreet_019](https://x.com/simarpreet_019) on X.

Include what you found, how to reproduce it, and the Thermo version (`thermo version`). You'll get a reply as soon as possible, and credit in the release notes if you'd like.

Only the latest release gets security fixes. What Thermo does and doesn't do is described in the [README's Security section](README.md#security).
