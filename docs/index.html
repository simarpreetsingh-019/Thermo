Install

Ready in ten seconds.

macOS 13 or later. Apple Silicon and Intel.

brew install --cask simarpreetsingh-019/thermo/thermo

Recommended. Adds the thermo Terminal command too, and skips the macOS warning because Homebrew verifies the download.

curl -fsSL https://raw.githubusercontent.com/simarpreetsingh-019/Thermo/main/install.sh -o install.sh
bash install.sh

No Homebrew needed. Checks the SHA-256 checksum, GitHub attestation and code signature before installing anything, and offers to add the thermo command. Read it first, it's short.

Get Thermo.zip from GitHub Releases, unzip, and drag Thermo into Applications.

macOS will say it can't verify Thermo. That's normal: Thermo is free and open source but not yet notarized by Apple (a paid program). It means "Apple hasn't checked this", not "this is harmful". To open it once:
  1. Double-click Thermo and click Done.
  2. Open System Settings → Privacy & Security and scroll down.
  3. Click Open Anyway next to Thermo, then confirm with Touch ID or your password.
macOS remembers your choice. On macOS 14 and earlier, right-click → Open also works. For the thermo command, use ⚙ → Connections → Install thermo command.

Want to check the download yourself?

shasum -a 256 ~/Downloads/Thermo.zip   # compare with the release notes
gh attestation verify ~/Downloads/Thermo.zip --repo simarpreetsingh-019/Thermo
Privacy

Your Mac's data
stays on your Mac.

No telemetry

The only network request is a daily update check against GitHub Releases. It sends nothing about you.

No admin rights

Public macOS APIs only. No kernel extensions, no helper tools, no passwords.

Verified updates

Every update must match its SHA-256 checksum and pass a code-signature check before it's installed.

Locked-down API

Off by default. Localhost only, read-only, token-protected, and it refuses requests from web pages.
